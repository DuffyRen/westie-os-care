# Westie OS · 西高地养成计划

在线访问：<https://duffyren.github.io/westie-os-care/>

一套围绕单只西高地白梗建立的成长管理原型。它把饮食、运动、健康观察、美容护理和养成手册放进同一个闭环：记录今天 → 与个人计划对比 → 给出最多三个优化方向。

## 已实现

- 今日成长罗盘：综合饮食、运动、健康观察与护理完成度
- 可编辑对比计划：日粮和轻度活动使用个人计划值，不伪装成通用医学标准
- 两步每日记录：数量记录 + 健康状态观察，本地持久保存
- 饮食模块：四餐时间线、喂食器校准、食欲/饮水/便便反馈
- 运动模块：短时嗅闻、轻游戏、正向训练与幼犬运动边界
- 健康模块：疫苗/检测记录、严重症状分流、周期护理提醒
- 美容模块：梳毛、嘴边清洁、耳朵/足间、口腔护理节奏
- 养成手册：分类、搜索、主题内容与“标准”边界说明
- 家庭同步：显示谁完成了喂食或活动，减少重复照护
- 本地优先：浏览器本地保存，并支持导出 JSON 档案
- 响应式布局：桌面侧栏与手机底部导航；支持减少动态效果

```

```

## 初始档案

原型带入已有记录作为初始值：公犬、2026-04-20 出生、最近体重 2.5 kg、喂食器每份约 17 g、当前每日计划 102 g。102 g 只代表这只狗当前使用的个人计划，不是所有西高地幼犬的统一标准。

健康信息用于日常管理与就医沟通，不替代兽医检查、诊断或处方。出现呼吸困难、持续呕吐、明显虚弱、血便、抽搐/昏厥或疑似触电/中毒时，界面会引导用户直接联系急诊兽医，不等待总分判断。
